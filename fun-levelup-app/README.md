# 퇴근까지 레벨업 (Fun + Practical Prototype)

직장인의 근무시간(09:00~18:00)을 게임처럼 버티게 해주는 **재미형 + 실무형 하이브리드 앱**입니다.

## 핵심 기능

### 재미형
- 퇴근 카운트다운 (18:00 기준)
- 포모도로 타이머 (25분)
- XP/레벨업 + 미션/배지

### 실무형
- 실무 태스크 등록 (우선순위 P1/P2/P3 + 예상 뽀모)
- 근무시간 플래너 체크리스트 (09~18 블록)
- 업무 브리핑 자동 생성/복사 (메신저 공유용)

## 실행 방법 (Windows/Mac 공통)

### 방법 A) 파일 더블클릭
1. `index.html`을 Chrome/Edge로 열기
2. 바로 사용 가능

### 방법 B) 로컬 서버
```bash
# fun-levelup-app 폴더에서
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속

## 파일 구조
- `index.html` : UI 구조
- `style.css` : 네온/글래스모피즘 스타일
- `app.js` : 상태/타이머/태스크/브리핑 로직
- `PLAN_EXECUTION.md` : 계획 및 실행 기록

## 참고
- 데이터는 브라우저 localStorage에 저장됩니다.
- 한국 직장인 밈 감성은 앱 내 코멘트 문구에 반영했습니다(칼퇴/월요병/점심시간 등).
