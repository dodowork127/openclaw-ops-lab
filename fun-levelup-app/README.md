# 퇴근까지 레벨업 (Content Pack v1)

재미형 + 실무형 하이브리드 앱에 **콘텐츠 확장팩 v1**을 적용했습니다.

## 주요 기능

- 랜덤 이벤트(회의 소집/점심 버프/긴급 수정 등)
- 스트레스 게이지 + 보상/패널티
- 직장인 클래스(자동화 닌자/집중 마스터/보고서 장인)
- 일일 업적 + 주간 타이틀(칼퇴의 신 등)
- 실무 태스크(P1/P2/P3)
- 근무시간 자동모드(평일 09:00~18:00)
- 브리핑 템플릿 3종
  - 팀장 보고용
  - 개인 회고용
  - 퇴근 전 요약
- 주간 통계 카드(완료 태스크/포모도로/XP/완료율)

## 실행 방법 (Windows/Mac 공통)

### A) 파일 더블클릭
`index.html`을 Chrome/Edge로 열면 실행됩니다.

### B) 로컬 서버
```bash
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`
