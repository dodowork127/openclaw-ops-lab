# PLAN_EXECUTION - 퇴근까지 레벨업

## 1) 목표
- 오늘 밤 테스트용으로 바로 체험 가능한 재미형 앱 제작
- UI가 그럴듯하고, 설치 없이 실행 가능해야 함(회사 Windows PC 포함)

## 2) 요구 해석
- 사용자 컨펌 없이 자율 개발
- 재미 요소 + 업무 보조 결합
- 실행 방법 문서화 필수(README)
- 계획과 실행 과정을 MD로 기록 후 커밋

## 3) 설계 결정
- 포맷: 정적 웹앱(HTML/CSS/JS)
- 이유:
  - Windows/Mac 공통 실행이 가장 쉬움
  - 배포/설치 없이 즉시 테스트 가능
  - 추후 Electron/PWA로 확장 쉬움

## 4) MVP 스코프
1. 퇴근 카운트다운(18:00)
2. 포모도로 타이머(25분)
3. 퀘스트 3개 + 완료/삭제
4. XP/레벨업
5. 미션 3종 + 배지
6. localStorage 저장

## 5) UI 원칙
- 다크 네온 + 글래스모피즘
- 카드형 대시보드
- 핵심 지표(퇴근시간/레벨/완료수) 상단 집중 배치

## 6) 실행 로그

- 정적 파일 구조 완성
- 브라우저 실행 기준 의존성 없음
