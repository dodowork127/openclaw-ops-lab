# PLAN_EXECUTION - 퇴근까지 레벨업 v2

## 1) 목표
- "재미형이 너무 단순" 피드백 반영
- 실무형 기능을 기획 후 즉시 추가
- 내일 근무시간 WhatsApp 테스트에 바로 쓸 수 있는 형태로 개선

## 2) 기획 방향
- 기존 게임화 요소는 유지(동기 부여)
- 실제 업무 흐름(우선순위, 시간블록, 보고)을 한 화면에 통합

## 3) 기능 기획 (추가)
1. **실무 태스크 모델 확장**
   - 제목 + 우선순위(P1/P2/P3) + 예상 뽀모
2. **근무시간 플래너(09~18)**
   - 시간 블록별 체크
3. **업무 브리핑 자동 생성**
   - 완료/잔여/집중 횟수를 텍스트로 출력
   - 복사 버튼으로 메신저 전송 쉽게
4. **밈 감성 라인**
   - 칼퇴/월요병/점심시간 등의 직장인 밈 문구 반영

## 4) 참고 조사
- web_search API 키 미설정으로 실시간 검색은 수행 불가
- 일반적으로 널리 쓰이는 한국 직장인 밈 키워드(칼퇴, 월요병, 점심시간)를 UI 카피에 반영

## 5) 실행 로그
- [x] `index.html` 실무형 카드(플래너/브리핑) 추가
- [x] `style.css` 카드/폼/우선순위 배지 스타일 확장
- [x] `app.js` 태스크 모델/브리핑 생성/복사 로직 구현
- [x] `README.md` 기능 설명을 하이브리드 형태로 갱신

## 6) 검증 체크
- 정적 파일 기반으로 Windows/사내 PC 브라우저 실행 가능
- 브리핑 생성 버튼 클릭 시 공유 가능한 텍스트 생성
- localStorage 상태 저장 유지

## 7) 다음 단계 제안
